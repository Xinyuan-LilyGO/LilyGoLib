<h1 align = "center">LilyGo T-Vibe-Dev</h1>


## `1` 概述

* 本文列出初代 `LILYGO T-Vibe-Dev` 的硬件规格.


### 控件和接口

| 项目 | 说明 |
| --------------------------- | --------------------------------------------------------------------------- |
| 电源开关 | 控制设备电源；拨向 USB-C 接口可开机 |
| 复位按钮 | 复位 ESP32-S3；不能作为可编程输入使用 |
| 轨迹球 | 四个方向开关和一个中央开关 |
| 轨迹球中央开关 | 同时连接到 GPIO0，并用作下载模式按钮 |
| 键盘 | 由专用 ESP32-C3 通过 I2C 管理的迷你键盘 |
| USB-C | 供电、充电、固件上传、USB CDC 和原生 USB 功能 |
| MicroSD 卡槽 | SPI 存储，与显示屏共用 SPI 总线 |
| Grove 接口 | 初代 T-Deck 上的 HY2.0-4P UART 接口 |
| 键盘编程接口 | 用于为键盘 ESP32-C3 编程的六针接口 |

### 硬件特性

| 特性 | 规格 |
| ------------------- | ------------------------------------------------------------------- |
| SoC | [Espressif ESP32-S3FN16R8][1]，双核 LX7，最高 240 MHz |
| 无线功能 | 2.4 GHz Wi-Fi 和 Bluetooth 5 LE |
| Flash | 16 MB |
| PSRAM | 8 MB OPI |
| 显示屏 | 2.8 英寸 ST7789 IPS LCD，320 x 240，SPI 接口 |
| 触控控制器 | GT911 电容式触控，I2C 接口 |
| 键盘控制器 | ESP32-C3 I2C 从设备 |
| 指向设备 | 五开关轨迹球 |
| 麦克风 ADC | Everest Semiconductor ES7210；连接 MIC1 和 MIC3 |
| 扬声器 | I2S 输出，带板载功率放大器 |
| 显示屏背光 | 16 级脉冲控制背光驱动器 |
| 存储 | MicroSD 卡槽，SPI 接口 |
| 电池监测 | ADC GPIO4 连接到 2:1 电阻分压器 |
| GNSS | 通过 Grove UART 连接外部模块|

[1]: https://www.espressif.com/en/products/socs/esp32-s3 "ESP32-S3"

> [!IMPORTANT]
>
> 显示屏、MicroSD 卡和 SX1262 共用一条 SPI 总线.一次 SPI 事务期间只能有一个片选信号为低电平.使用 LilyGoLib 的开发板 API 时，总线管理由库处理.

> [!NOTE]
>
> GPIO0 同时连接轨迹球中央开关，也是 ESP32-S3 的下载模式启动配置引脚.要正常启动，请在复位期间松开轨迹球.

### I2C 设备地址

| 设备 | 7 位地址 | 是否共用总线 |
| ---------------------------- | ------------- | ---------- |
| GT911 触控控制器 | 0x14 或 0x5D | 是 |
| ES7210 麦克风 ADC | 0x40 | 是 |
| ESP32-C3 键盘控制器 | 0x55 | 是 |

### 电源说明

* GPIO10 用于使能开发板外设电源轨.LilyGoLib 会在初始化开发板时将其置高.
* T-Vibe-Dev 没有可由软件控制的 PMIC 或电量计.电池电压通过 GPIO4 估算，因此无法获取充电电流、电池温度和精确电量.
* 显示屏背光不使用 PWM 控制.背光驱动器通过 GPIO42 上的脉冲在 16 个亮度等级间切换.
